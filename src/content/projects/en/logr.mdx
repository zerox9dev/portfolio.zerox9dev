## Task

I'm a freelancer and I track time every day. I'd tried Toggl, Clockify and Harvest — every time it was the same story: either expensive for basic features, or free but with a UI like a nuclear plant control panel. And most trackers stop at “track”, so you still need a separate tool to bill the client. All I needed was simple: start a timer, see my day, and get an invoice at the end of the month. So I decided to build it myself.

## Solution

I did the full product cycle on my own — from design to development. The first version was built in a day: a keyboard-first timer, a timeline, clients and one-click invoices. Since then logr has grown into a full app — and it closes the loop: track → bill → get paid.

The landing page lets you try the timer right on the first screen, without signing up: pick a project, press Start, switch projects — every session lands in today’s list.

<ProjectShot src="/projects/Logr/landing-pair.png" caption="Landing page on web and mobile with a timer you can try without an account" />

Inside, the app moved to a sidebar layout with real pages — Dashboard, Projects, Sessions, Clients, Invoices, Reports and Settings — and a ⌘K command palette. Invoices are built from a client’s unbilled sessions and can be shared by a public link. A client can be marked as an employer with a salary, and logr turns it into an hourly rate. Worklogs can be pulled in from Jira Cloud, and an in-app AI assistant can answer “show unbilled for Acme and draft an invoice”.

Under the screens sits a small design system: every block — timeline, projects and tasks, billable hours, goals, activity, daily summary — is a component with desktop and mobile variants and both a filled and an empty state. That is why an empty account does not look like a broken one.

The backend moved from Supabase to self-hosted PocketBase, so the whole thing ships as one Docker Compose file: anyone can run their own copy and keep their data. The interface works in English, Ukrainian and Russian.

## Result

logr is live and fully open-source under AGPL-3.0 — I track all my own time exclusively through it, fixing bugs as I hit them. Real-time dogfooding. Use it at logr.work or host it yourself: found a bug — open an issue, want a feature — PRs welcome.
